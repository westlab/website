# 国際標準化の実績（調査メモ）

2026-10-29 時点で、IEEE SA の公式ページなどを確認した結果。標準化ページを作るときの元データにする。

## 規格

| 規格 | 名称 | 種別 | 西先生の役職 | PAR承認 | 規格承認 | 発行 |
|---|---|---|---|---|---|---|
| [IEEE 1451.1.6-2025](https://standards.ieee.org/ieee/1451.1.6/11619/) | Standard for a Smart Transducer Interface for Sensors, Actuators, and Devices--Message Queue Telemetry Transport (MQTT) for Networked Device Communication | Standard | WG Chair（MQTT Interface Working Group） | 2024-05-22 | 2025-06-19 | 2026-02-06 |
| [IEEE 2992-2025](https://standards.ieee.org/ieee/2992/10614/) | Recommended Practice for Data Expression, Exchange, and Processing in Smart Agriculture | Recommended Practice | WG Chair（DEEP-SA Working Group） | 2021-05-21 | 2025-09-10 | 2026-02-20 |
| [IEEE 1451.0-2024](https://standards.ieee.org/ieee/1451.0/11001/) | Standard for a Smart Transducer Interface for Sensors and Actuators--Common Functions, Communication Protocols, and Transducer Electronic Data Sheet (TEDS) Formats | Standard | 策定に貢献（Chair は Eugene Y. Song 氏, NIST） | 2022-09-21 | 2024-02-15 | 2024-06-26 |

- 3規格とも主管は IEEE Industrial Electronics Society（IES）Standards Committee。1451.1.6 は IM/ST との共同
- 「規格承認」は IEEE SA Standards Board の承認日
- 1451.1.6 は当初 P21451.1.6 として 2018-03 に PAR を申請し、のちに P1451.1.6 へ番号を変更した（[NesCom 議事録 2023-09-20](https://standards.ieee.org/wp-content/uploads/2023/06/nescom-09202023min.pdf)）。researchmap の「P21451-1-6 Chair（2017-11〜）」はこの活動
- 2992 の副議長（Vice Chair）は Janaka Wijekoon 氏（提供資料による）
